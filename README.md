# Protótipo - Estacionamento Campus
Este protótipo é um aplicativo de linha de comando para gerenciamento do estacionamento.

Ele cobre dois requisitos principais:

1. Manter o login do usuário ativo (sessão persistente)
2. Operação parcialmente offline utilizando um banco de dados local (SQLite).

Para executar o aplicativo, certifique-se de ter o Python 3 instalado em sua máquina.

Abra o terminal na pasta onde os arquivos estão salvos e execute o comando:

```bash
python main.py
```

Os arquivos de banco de dados (`.db`) e de sessão (`.json`) serão gerados automaticamente.
